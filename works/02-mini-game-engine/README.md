## Что реализовано

Программа создаёт трёхмерную игровую сцену средствами OpenGL:

- фон и пол покрыты текстурой из `background.ppm`;
- модель игрока покрыта текстурой из `crate.ppm`;
- в сцене есть кубы и объёмные морковки с ботвой, освещение и материалы;
- любую модель можно выбрать мышью: пока удерживается левая кнопка,
  модель подсвечивается и перемещается вслед за указателем;
- ящик игрока управляется клавиатурой, не проходит сквозь препятствие и
  взаимодействует с морковками;
- при соприкосновении с игроком морковка исчезает, а счёт увеличивается;
- после исчезновения всех морковок поверх сцены появляется яркая
  надпись `ПОБЕДА!`;
- у моделей есть проекционные тени;
- ступенчатость уменьшается четырёхкратным суперсэмплингом.

Сцена и пути к текстурам читаются из внешнего текстового файла. Поэтому
положение камеры, света и моделей можно менять без перекомпиляции.

## Сборка

Программа рассчитана на Windows и использует системные библиотеки OpenGL
и GLU. Нужен компилятор GCC/MinGW-w64 с поддержкой C++17.

Из папки `works/02-mini-game-engine`:

```bat
.\build.bat
```

То же самое вручную:

```bat
g++ -std=c++17 -Wall -Wextra -Wpedantic -O2 -o mini-game-engine.exe main.cpp -lopengl32 -lglu32 -lgdi32 -luser32
```

Если команда `g++` не найдена, MinGW-w64 можно установить командой:

```powershell
winget install -e --id BrechtSanders.WinLibs.POSIX.UCRT
```

После установки нужно открыть новый терминал.

## Запуск

Основная сцена `scene.txt`:

```bat
.\mini-game-engine.exe
```

Другая сцена:

```bat
.\mini-game-engine.exe scene-example.txt
```

Справка без открытия графического окна:

```bat
.\mini-game-engine.exe --help
```

Программа не читает стандартный ввод: входными данными служит файл
сцены, переданный первым аргументом. Если аргумент отсутствует, программа
ищет `scene.txt` в текущей папке и рядом с исполняемым файлом.

## Управление

- левая кнопка мыши по модели и перемещение мыши — выбрать и перетащить;
- `W`, `A`, `S`, `D` или стрелки — двигать ящик игрока;
- `R` — вернуть все модели в исходное состояние;
- `T` — включить или выключить текстуры;
- `H` — включить или выключить тени;
- `G` — включить или выключить сглаживание;
- `F1` — вывести справку в консоль;
- `Esc` — выйти.

## Формат входных данных

Пустые строки пропускаются. Текст после `#` считается комментарием.
Все обязательные команды можно располагать в любом порядке:

```text
camera eyeX eyeY eyeZ targetX targetY targetZ
light x y z
background путь_к_текстуре.ppm
object имя форма x y z размер оформление значение роль
```

Допустимые значения:

- форма: `cube`, `sphere` или `carrot`;
- оформление: `texture` либо `material`;
- для `texture` значение — путь к PPM-файлу формата P3;
- для `material` значение — `gold`, `ruby`, `jade`, `stone` или `carrot`;
- роль: `player`, `collectible` или `obstacle`.

В сцене должны быть ровно один `player`, хотя бы один `collectible` и не
менее двух моделей. Относительные пути к текстурам отсчитываются от
папки файла сцены. Для куба `размер` — длина ребра, для сферы — диаметр,
а для морковки — общий масштаб модели.

### Пример входных данных

```text
# Камера смотрит из точки (8, 7, 13) в начало координат.
camera 8 7 13 0 0 0
light -4 9 4
background background.ppm

object player cube -3 0.75 3 1.5 texture crate.ppm player
object target carrot -2 0.68 -2 1.5 material carrot collectible
object column cube 0 1.25 1 2.5 material stone obstacle
```

Готовые примеры находятся в `scene.txt` и `scene-example.txt`.
