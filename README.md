# Самостоятельная работа №1 — Cornell Box

Решение задания по программированию на C++ и OpenGL.

**Автор:** Ольга Иевлева, группа ОБ-ППО-25.

Программа строит трёхмерную сцену Cornell Box: комнату без передней
стены, два блока, потолочный источник света и прозрачную сферу.
Положение камеры и координаты поверхностей соответствуют параметрам
из задания.

## Что реализовано

- освещение сцены восемью точечными источниками;
- разбиение крупных граней на сетку до 16×16;
- процедурные текстуры плитки и дерева;
- проекционные тени на полу с использованием stencil-буфера;
- сглаживание методом суперсэмплинга;
- прозрачная стеклянная сфера GLU;
- интерактивное управление камерой;
- сохранение результата в BMP.

## Файлы

- `works/01-cornell-box/main.cpp` — исходный код программы;
- `works/01-cornell-box/readme.txt` — описание выполненных пунктов;
- `works/01-cornell-box/build.bat` — сценарий сборки для Windows.

Для запуска также требуется входной файл `geometry.txt` с параметрами
камеры и геометрией из задания. Его необходимо положить рядом с
исполняемым файлом либо передать программе первым аргументом.

## Требования

- Windows;
- MinGW-w64 с компилятором `g++`;
- системные библиотеки `opengl32`, `glu32`, `gdi32` и `user32`.

GLUT устанавливать не требуется.

## Сборка

Откройте терминал в папке `works/01-cornell-box` и выполните:

```bat
g++ -std=c++17 -Wall -Wextra -O2 -o cornell-box.exe main.cpp -lopengl32 -lglu32 -lgdi32 -luser32
```

Также можно запустить:

```bat
build.bat
```

## Запуск

```bat
cornell-box.exe geometry.txt
```

Сохранить один кадр и завершить программу:

```bat
cornell-box.exe geometry.txt --screenshot screenshot.bmp
```

Показать справку:

```bat
cornell-box.exe --help
```

## Управление

- левая кнопка мыши или стрелки — вращение камеры;
- колёсико мыши, `+` и `-` — приближение;
- `R` — вернуть исходную камеру;
- `G` — изменить плотность разбиения полигонов;
- `T` — включить или выключить текстуры;
- `H` — включить или выключить тени;
- `A` — включить или выключить сглаживание;
- `F5` — сохранить `screenshot.bmp`;
- `Esc` — выход.
